# 記事公開チェックリスト（書き手・ほかのボット向け）

公開前に必ず確認し、push後は `python3 scripts/check.py` を実行して「NG 0」を確認してください。

- [ ] front matter に `image:`（1200×675前後のJPG、`assets/img/posts/<slug>.jpg`、和の色・青海波・小石の作風、他サイトの画像は使わない）
- [ ] 冒頭に「この記事のポイント」枠（`<div class="keypoints">`、3項目）
- [ ] 図を最低1つ（`{% include bars.html title="…" data="ラベル:数値|…" max="100" unit="%" caption="出典…" %}` か `figure.html`）。本文にある数字だけを使う
- [ ] 数字には出典と【確認】【推定】【推測】を付ける
- [ ] スマホ（360/390px）で横にずれない：長い表はそのままでOK（自動で横スクロール）、固定幅の要素を置かない
- [ ] 文章は短い段落で。1文は60字前後まで
- [ ] 埋め込み（YouTube・X）は実在と内容を確認してから
- [ ] 公開後、トップ・宝石箱から記事をクリックして開けること（check.pyが自動確認）
