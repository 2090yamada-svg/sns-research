## 記事の追加方法
1. `_posts/` に `YYYY-MM-DD-英数字のタイトル.md` というファイルを作ります。
2. 先頭に次のような情報を書きます。
   ```
   ---
   layout: post
   title: "記事タイトル"
   date: 2026-11-02
   ---
   ```
3. 本文をMarkdownで書き、mainブランチにpushすると数分で公開されます。
4. このREADMEの記事一覧にも1行追加します。
